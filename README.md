# Salsal VM — Portfolio

Premium personal portfolio for **Salsal VM**, Senior Flutter Developer, Mobile Engineer, and Full Stack Developer.

## Stack

- React (Vite)
- JavaScript
- Tailwind CSS v4
- Framer Motion
- React Icons

## Run locally

```bash
cd /Users/vava/Documents/portfolio
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
