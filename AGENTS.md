# Portfolio — Agent guide

## Deployment rule (owner's standing instruction)
Never deploy without the owner's explicit go-ahead. Do not deploy, publish or release anything — hosting, APIs or workers, production database migrations, seeds or imports, app-store builds, or pushes to any live service (for example Apps Script on a live Google Sheet) — until the owner says to deploy in the current conversation. Build, test and prepare locally, then stop and ask. This applies to every project on this Desktop.
